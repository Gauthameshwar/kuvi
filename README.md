# Kuvi

Kuvi is a small desktop robot built around the Waveshare ESP32-S3-Touch-AMOLED-1.75.

## Serviceable enclosure

The two-piece head allows the Waveshare to be secured before installing the battery tray. A screwless keeper retains the rear speaker. This snapshot precedes the internal rear USB extension.

Open [the current snapshot](revisions/02-serviceable/kuvi.FCStd) directly in FreeCAD. Its [Python helper](revisions/02-serviceable/model.py) opens and inspects the saved solids using FreeCAD Python; no reconstruction scripts are required.

These dimensions are provisional. This snapshot is for design review, not printing.

See [part references](references/README.md) and [contributor guidelines](AGENTS.md).
