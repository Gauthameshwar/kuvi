# Kuvi

Kuvi is a small desktop robot built around the Waveshare ESP32-S3-Touch-AMOLED-1.75.

## Initial concept

The first layout separates the front carrier, main shell and rear cover, with preliminary mounts for the screen, battery, speaker and vibration module.

Open [the current snapshot](revisions/01-concept/kuvi.FCStd) directly in FreeCAD. Its [Python helper](revisions/01-concept/model.py) opens and inspects the saved solids using FreeCAD Python; no reconstruction scripts are required.

These dimensions are provisional. This snapshot is for design review, not printing.
