# Future firmware

Application source will live in `src/`. No framework or build system has been selected yet. Do not install or assume an Arduino, ESP-IDF, or PlatformIO toolchain until the firmware work begins.

Planned behavior includes the face animation, button actions, audio, battery/charging status, and brief low-intensity haptic cues. Haptic supply voltage, GPIO mapping, and PWM timing remain electrical/firmware decisions; the CAD wire routes are not a wiring schematic.
