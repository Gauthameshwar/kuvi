# Initial concept

The first complete layout: a three-piece head, preliminary battery and speaker mounts, a lower vibration module and separate button extensions.

This snapshot shows the original proportions and component arrangement. It uses provisional dimensions and more screws than the later design. It is kept for design history, not printing.

Open `kuvi.FCStd` in FreeCAD. `model.py` opens and inspects the saved solids; it does not rebuild this historical version.
