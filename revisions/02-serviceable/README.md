# Serviceable enclosure

The head becomes two pieces: a front carrier and one rear casing. The Waveshare is screwed down before the separate battery tray is installed. A screwless keeper holds the speaker, and the vibrator has a removable mounting arrangement.

This is the main architectural change from the first concept. Component fits were still provisional. It predates the internal rear USB extension and final measured mounts.

Open `kuvi.FCStd` in FreeCAD. `model.py` opens and inspects the saved solids; this snapshot is for comparison, not printing.
